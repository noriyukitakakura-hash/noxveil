# Noxveil

A map where only the places you have actually been are lit. Everywhere else
stays dark.

This repository is the public face of the app: the
[privacy policy](https://noriyukitakakura-hash.github.io/noxveil/privacy.html),
the [support page](https://noriyukitakakura-hash.github.io/noxveil/support.html),
and the scripts that build the map the app carries.

**The app's own source is not here.** What is here is what the app's users and
the Open Database License are owed: a plain statement of what the app does with
a recording, and a reproducible way to make the map file it ships.

- `index.html`, `privacy.html`, `support.html` — served by GitHub Pages
- `tools/` — the basemap build, and why it is public ([details](tools/README.md))

Roads are © OpenStreetMap contributors, [ODbL](https://opendatacommons.org/licenses/odbl/).
Coastlines are from Natural Earth, public domain.
